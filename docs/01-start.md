# 从零复刻：先做什么

先确认你的主控是 **ESP32-S3-WROOM-1U-N16R8**。本教程对应 12 键、双轴无按压摇杆、EC11 旋钮、两块 PCB；不要把官方 13 键或早期 STM32 文件混进来。

| 步骤 | 你要做什么 | 完成标志 |
|---|---|---|
| 1 | 打开嘉立创EDA工程，确认控制板与键轴板 | 看见两板原理图及 PCB |
| 2 | 对照两板 BOM 和机构清单采购 | 缺失 MPN 已确认，封装/排线方向一致 |
| 3 | 导出 Gerber，分别 PCB 下单；外壳/面板单独制作 | 工厂预览核对尺寸、层数、孔位 |
| 4 | 焊接并检查电源、极性和短路 | 通电前确认供电路径与 GND |
| 5 | 用首次烧录包给空白板写入 | 能枚举设备并回读版本 |
| 6 | 连接排线，固定电池、天线、上下壳 | 无挤压、无裸露金属接触 PCB |
| 7 | 安装配置软件，逐键检查 | 保存后回读一致，断连重连仍保留 |

准备可调温烙铁、助焊剂、镊子、万用表、细螺丝刀和有数据线的 USB 线。无焊接经验可委托商家焊接，但要让商家按本项目 PCB/BOM 和 LED 方向说明操作。

第一次烧录可能需要将 ESP32-S3 拉入 ROM 下载模式：断电，GPIO0 拉低后复位/重新供电，连接板上实际 USB/串口焊盘。**板上焊盘以原理图与实体标注为准，不把示意图当针脚位置图。**
