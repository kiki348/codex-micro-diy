# PCB、外壳、面板与优惠

## PCB

嘉立创EDA导入 `hardware/codex-micro-20260810.epro2`。分别打开“控制板”和“键轴板”，运行 DRC，再从“导出 → PCB制板文件(Gerber)”导出。不要选盖板或面板工程当控制板。

本次网页编辑器完成检查后，控制板显示1项“原理图与PCB网表不一致”，不能记为DRC通过。需要先查看差异，确认冻结版本的板图和原理图对应关系；不要直接导入网表改坏已有布线。控制板预览为4层、约89.995×49.876mm。这只是编辑器估算，不替代工厂 DFM 和实际板厚核对。Gerber、两板 BOM 和 CPL 需要同一版本；外购手焊料应与 SMT 料区分。

提交前检查层数、板框、钻孔、USB焊盘和电池端子；确认字体/丝印遮挡、正反面、工厂工艺、拼板方式。已有 Gerber 在 `hardware/gerber/`，若该目录注明导出未完成，则请按上述工程重新导出，不使用旧 STM32 Gerber 顶替。

## 3D 打印

外围优先 `outer-tolerance.step`，下壳用 `lower-housing.step`。无公差外围是历史对照，可能需要打磨。透明导光件按上游建议采用交叉填充，普通不透明件可以与透明件分别制作。

`optional/` 键帽为可选试制，先打印单颗检查轴座、裙边与相邻键间隙，再批量打印。不同轴体接口不能只凭外观看作兼容。

## 面板与 CNC

面板工程用于导出开孔轮廓和印刷位置；`panel-print-100mm.pdf` 只是印刷图案，不等于开孔制造图。按设计设置2mm亚克力，先核对四孔和旋钮/摇杆开口。金属底板使用 `base-plate.step`，CNC前确认材料、厚度、倒角和绝缘措施。

## 合法领取优惠

PCB、3D打印、面板、CNC券分开查看账号当前活动和适用品类，下单前以结算金额为准。历史免费记录不保证新用户现在同样免费。

嘉立创公开3D规则对尺寸、体积和单个连通模型有条件，新增模型可能带工厂标识；不把多颗键帽用细杆连接就宣称必定符合免费资格，不以多账号规避活动限制。
