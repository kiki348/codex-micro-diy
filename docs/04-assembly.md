# 焊接与装配

1. 分开核对控制板与键轴板 BOM，先焊低矮元件、芯片，再焊座子和连接件。电池暂不连接。
2. 重点检查供电、GND、USB和电池端子，测量是否短路、元件有无反向，必要时让焊接商家检查。
3. **键轴板 LED 方向标志有误**：按上游说明，LED焊盘朝上观察时，GND对准左下焊盘。仍须按具体 LED 型号和板上网络核对，不只看丝印箭头。
4. 先做控制板首次烧录和枚举检查，再装壳。复位或唤醒时松开摇杆，避免中心校准偏移。
5. 金属底板和 PCB 之间做好绝缘。用 M2×8 平头/超薄平头自攻螺丝固定下壳与板子，先手拧确认不会顶到元件。
6. 电池固定在上游设计右侧空间，避开排线座；按实际极性连接。天线按原设计走线固定，连接座子时垂直轻压，避免偏斜损伤。
7. 接好16pin排线和锁扣，摆放上板。合壳时把余线留在电池尾部空隙，不能压在四角支撑与壳边。
8. 四角放 M3×3 隔离柱，面板装 M3×14 内六角螺丝，穿过隔离柱后均匀拧上 M3 螺母，不用螺丝强拉变形的壳体。
9. 贴1mm防滑脚垫，装轴与键帽。检查每键回弹、旋钮旋转/按压及摇杆两个方向轴。

不要把已组装照片当作电池极性或焊盘位置的唯一依据。没有确认焊接方向和供电之前，不接电池继续试错。
