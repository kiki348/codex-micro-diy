# 配置软件使用

下载 `WorkAxis-Windows-x64-v18.zip` 并完整解压，运行 WorkAxis.exe，连接本 DIY 键盘的 USB。当前为未签名测试发行；操作系统可能提示发行者未验证。

1. 确认设备出现在软件中，检查固件版本为 `.18`。
2. 先使用默认配置，给一个通用按键设置简单键码。
3. 保存后回读设备配置，并断连重连确认没有丢失。页面显示保存成功并不独立证明设备已经保存。
4. 添加、删除图层以及切换配置后分别核对活动层；当前交付说明约定旋钮长按3秒循环配置图层，**不要混用历史 v8 的短按切换操作说明**。
5. 设置灯光后确认重连状态。Codex软件内的官方输入设置与通用键位分开核对。

只打开一个配置程序，避免多个进程同时占用 HID。更新固件前关闭配置软件。恢复默认前备份，自定义键位/灯光/智能动作可能被覆盖。

已有运行和配置读写记录，不等于全部软件兼容或第二台干净Windows安装已通过。[验证范围](validation.md)。
