# 常见问题

| 现象 | 优先检查 |
|---|---|
| 软件找不到键盘 | 数据USB线、供电、USB枚举、是否处于ROM下载模式 |
| 保存失败或RPC超时 | 关闭其他HID占用程序，保存后回读，不反复同时重试 |
| 一个键无响应 | 轴体/座子/焊接、74HC165原始扫描位、上拉路径；换键码不修硬件 |
| LED不亮/方向异常 | 型号、供电、GND与错误丝印方向，勿带电反复拆焊 |
| 摇杆中心偏移 | 松手复位；检查双轴ADC，不声称它有下压键 |
| 外壳卡不进去 | 版本、公差、打印方向；先试装，不靠螺丝强压 |
| 合壳后间歇断连 | 排线锁扣、挤压、金属底板绝缘、电池固定 |
| OTA失败 | 包的SHA256、目标固件HID接口、供电及是否只连接一把目标设备 |
| 芯片完全不启动 | ROM下载口、匹配启动程序/分区；不要全片擦除个人配置 |
| 与Codex有双触发 | 同一次实体操作分别记录模式和软件响应，不用模拟快捷键代替实测 |

提交 Issue 时给板型、版本、操作步骤和现象；去掉序列号、电脑用户名、配对信息与个人路径。推荐一次只改变一个条件。
