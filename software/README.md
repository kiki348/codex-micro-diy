# Windows 配置软件

WorkAxis 是基于官方 Input 应用二次开发的 Windows x64 配置软件，用于本 DIY 键盘设置键位、图层和灯光。桌面软件源码不公开，下载完整发行 ZIP 后运行 WorkAxis.exe。

EXE 旁的 DLL、locales 和 resources 都是运行依赖，不要只复制 EXE。目录中的压缩 JavaScript 是程序运行资源，不是桌面开发源码的单独开放授权。

本修改版保持原应用及依赖的署名，独立于官方产品。[使用教程](../docs/06-software.md) · [下载](../docs/downloads.md)。
